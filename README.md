# CatGirlCraft Modpack
This is the Git repository for the CatGirlCraft distributable modpack, as well as server mods.
## Clientside Manual Update Procedure
1. **Close Prism Launcher first.**
2. Click on your CatGirlCraft instance in the Prism Launcher.
3. In the menu on the right, click Folder.
4. Replace `mmc-pack.json` with the file from the modpack's .zip file.
   1. Always do this, to be on the safe side, as NeoForge updates often.
5. Open the `minecraft` folder.
6. Delete the `mods` folder entirely.
7. In the modpack's .zip file, find the same `mods` folder and drag it into the instance's `minecraft` folder.
8. If necessary, you should also update the CatGirlCraft resource pack by copying to/from `resourcepacks\CatGirlCraft`.
