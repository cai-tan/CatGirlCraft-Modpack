# CatGirlCraft Modpack
This is the Git repository for the CatGirlCraft distributable modpack, as well as server mods.
## Clientside Manual Update Procedure
1. Click on your CatGirlCraft instance in the Prism Launcher.
2. In the menu on the right, click Folder.
3. (Updating to v1.1) **IMPORTANT!** Replace `mmc-pack.json` with the file from the modpack's .zip file.
4. Open the `minecraft` folder.
5. Delete the `mods` folder entirely.
6. In the modpack's .zip file, find the same `mods` folder and drag it into the instance's `minecraft` folder.
7. If necessary, you should also update the CatGirlCraft resource pack by copying to/from `resourcepacks\CatGirlCraft`.
